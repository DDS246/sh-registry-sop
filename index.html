01

Purpose

This standard operating procedure (SOP) was developed to be used in conjunction with the REDCap database for the St. Helena diabetes registry. This SOP will help users to enter and manage registry data.

02

Scope

All persons using the diabetes registry database should use this SOP.

03

Requirements

  • Active REDCap user account
  • Access to the diabetes registry database
  • Internet access
  • Any necessary approvals

04

How to log into REDCap

  1. Open a web browser, e.g. Google Chrome, Microsoft Edge, etc.
  2. In the URL box, type https://caribdata.org/redcap.
  3. On the login page, enter your username and password
  4. Click Login.

Download this video

Note: Do not share your username or password with another person.

05

How to reset your REDCap password

  1. On the login page, click Forgot your password?.
  2. Enter your username.
  3. Click 'Send password reset email'.
  4. Check your email for the automated email from the REDCap system.
  5. Click the link 'Setup your new REDCap password' in the email.
  6. A browser will open, enter and re-enter your password.
  7. Click, Submit.

Note: Do not share your username or password with another person.

07

How to search the database

  1. Once logged into the project, click Add / Edit Records.
  2. In 'Data Search', select field to search by, e.g. First Name
  3. In 'Search query', enter value, e.g. michelle or henry.
  4. All possible matches will be listed.
  5. If no matches, then nothing will be listed.
  6. Select if the possible match is opened in 'Data Entry Form' or 'Record Home Page'.
  7. Click on the match in the list to open the record.

Download this video

Note:
  • Search query is not case sensitive.
  • Searching the database BEFORE you add a new record is important to prevent duplicates.

09

How to complete Baseline

  1. Click on 'Baseline' in Record Home Page of a new record.
  2. Enter values into the fields
  3. There are several options for saving:
Save & Stay

Remains in current form.

Save & Exit Form

Exits current form and returns to Record Home Page.

Save & Go To Next Form

Exits current form and opens next sequential form of the same record.

Save & Exit Record

Exits current record and navigates to Add / Edit Records page.

Save & Go To Next Record

Exits current record and opens next sequential record's Record Home Page. If in last record of database then exits current record and opens a new record's Record Home Page.

Save & Go To Next Instance/Add New Instance

Exits current record of a REPEATING form and opens next sequential instance of this form. If in last instance then the option to 'Save & Add New Instance' will be displayed.

Download this video

Note: Some fields are read-only as they are either:
  • system-generated by REDCap (e.g. Registry record key) or
  • auto-calculated (e.g. Age at date of baseline data entry)

10

How to complete Contact

  1. Click on 'Contact' in Record Home Page of the record.
  2. Enter values into the fields and save.
  3. To add a new instance at another date, either:
    • click grey plus sign '+' button next to this form on the Record Home Page;
    • click grey '+ Add new' button in the Repeating instruments grid on the Record Home Page;
    • in the last instance of the Contact form, click 'Save & Add New Instance'.

Download this video

Note:
  • In REDCap, the terms 'instrument' and 'form' and 'page' may be used interchangeably.
  • Repeating instruments are forms that can be entered multiple times, i.e. longitudinal data collection
    • All forms EXCEPT baseline are repeating instruments
  • Some forms, e.g. Contact, copies unchanging data (e.g. patient name) over from one instance into the other.

17

How to use the Form Status

  1. At the end of ALL forms, there is the field 'Form Status' whose default value = Incomplete.
  2. These options are colour-coded and correspond with the legend for status icons on the Record Home Page.
  3. The options should be used as follows:
    4. Incomplete

    Required fields in the form have not been completed.

    Unverified

    All required fields in the form have been completed.

    Complete

    Form has been reviewed by SI/JPD/SI.

Download this video

Note: The colour-coding of form status is consistent throughout the project.

18

Saving a record with blank/missing required fields

  1. The system will prompt you to enter data into required fields if blank/missing on saving the record.
  2. The options should be used as follows:
    3. Okay

    Saves and remains on the form.

    Ignore and leave record

    Saves record and navigates to Add / Edit Records page.

    Ignore and go to next form

    Saves form and navigates to next sequential form of the same record.

Download this video

Note:
  • Required fields are identified with '*must provide value' in red font under the field.
  • If requried fields are blank/missing then the Form Status should = Incomplete.

19

How to execute data quality (DQ) rules

  1. Under Applications on the left of your project, click 'Data Quality'.
  2. The options to execute/run DQ rules are as follows:
    3. All

    Executes both the built-in (rules A-I) and custom rules. Can take long to run.

    All except A&B

    Executes both the built-in and custom rules but excludes the built-in rules for blank values.

    All custom

    Executes only the custom rules, i.e. the rules that are manually written into the DQ module (rules # 1 onwards).

  3. Once records are flagged with discrepancies, a query can be opened and assigned via the Data Resolution Workflow (DRWF) feature within the DQ module:
    • click 'view' which appears after the numeric value in red indicating number of discrepancies found;
    • click '...comments' next to the discrepancy to open DRWF;
    • assign the query to the relevant user, notify them via email or REDCap Messenger and add comments.

Download this video

Note:
  • Tiered access to the Data Quality (DQ) module is assigned via User Rights.
  • The DQ module is used in conjunction with the Data Resolution Workflow (DRWF).
  • See the next section for guidance on how to correct discrepancies via DRWF.

20

How to correct data via Data Resolution Workflow

  1. Under Applications on the left of your project, click 'Resolve Issues'.
  2. If query was notified via REDCap Messenger, then you can also view it there (see video demo).
  3. Once data queries have been opened, a list of all unresolved issues will appear in DRWF:
    • click '...comment' to view details of the issue;
    • click the ID number under the column 'Record' to open the record;
    • correct the issue and click 'Save & Stay'.
    • the comment bubble next to the field allows you to access and respond to the DRWF query (see video below).
    • alternatively, return to DRWF and update the query to indicate it has been corrected.

Download this video

Note:
  • Tiered access to DRWF module is assigned via User Rights.
  • You can also access DRWF via the email link with the opened query assigned to you.
  • See the next section for guidance on how to open a query for the data manager, clinician, etc. via DRWF.

21

Saving a record with a data quality rule violation

  1. If a rule is violated, a message will appear on saving the form.
  2. If unsure how to correct issue, open query for the relevant team member via the DRWF comment option.
  3. Different members will be assigned to the below roles within the database:
    • Data Officer
    • Diabetes Clinician
    • Diabetes/Community Nursing Team
    • Laboratory Lead
    • Pharmacy Lead
    • Public Health Lead
    • Registry/Data Lead

Download this video

Note: If possible, always correct the issue instead of having to open a query in DRWF.

Troubleshooting

Cannot remember password

See the section on this page entitled 'Password' to see how to reset your password.

Unsure which person to assign the query

See all database roles in the section 'DQ Violation'.

Information security

Do not place passwords, personal information, patient information, confidential records, or API credentials in screenshots or videos.

Do not share confidential or sensitive patient information via email or WhatsApp or any other unsecured messaging app. Use DRWF / REDCap Messenger.
